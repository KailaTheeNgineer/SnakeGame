🐍 Snake Game | AI-Assisted Development

🎮 Project Overview

A classic Snake game developed in Java as part of a college assignment exploring AI-assisted programming (vibe coding). This project demonstrates how AI tools can assist in creating interactive applications.

⸻

🎯 Objective

Experiment with vibe coding to develop a functional Snake game while exploring the capabilities and limitations of AI-generated code.

⸻

🛠️ Technologies Used

* ☕ Java — Programming language
* 💻 Visual Studio Code — Development environment
* 🤖 Claude — AI-assisted code generation and development

⸻

✨ Game Features

* 🐍 Snake Movement — Control the snake around the game board.
* 🍎 Food Generation — Randomly generated food for the snake to collect.
* 🏆 Scoring System — Earn points as the snake grows.
* 💥 Collision Detection — Game ends when the snake hits an obstacle or itself.
* 🔄 Restart Functionality — Play again after the game ends.

⸻

🧠 Development Process

This project was developed through AI-assisted programming as part of an assignment focused on exploring vibe coding.

Development highlights:

* Used AI to generate the initial game structure and functionality.
* Explored how AI interprets programming instructions.
* Evaluated the generated code for functionality and potential improvements.
* Identified areas where debugging or modifications may be necessary.

⸻

🌱 What I Learned

This project provided an opportunity to explore the advantages and limitations of AI-assisted software development.

Key takeaways:

* Understanding how AI can accelerate the development process.
* Recognizing the importance of reviewing and testing generated code.
* Exploring how prompt clarity can influence the final result.
* Learning how AI-assisted development fits into modern software engineering workflows.
